# Dataset

**Chicago Crimes, 2001 to Present** (~7.8M records)

- Kaggle: https://www.kaggle.com/datasets/adelanseur/crimes-2001-to-present-chicago
- Original source: City of Chicago Data Portal

Download the CSV and save it here as:

```
data/Crimes_-_2001_to_Present.csv
```

The file is git-ignored because of its size. Only these columns are loaded:
`ID, Case Number, Date, Primary Type, Location Description, Arrest, Domestic, District, Ward, Community Area, Latitude, Longitude`
